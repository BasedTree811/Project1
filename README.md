# Электронная библиотека (apaas)

Flutter-приложение для просмотра, поиска и управления электронными книгами.  
Клиент обращается к PHP REST API (`library_api`) и базе данных MariaDB/MySQL.

## Возможности

- Авторизация и регистрация пользователей
- Каталог книг с **поиском по названию и жанру**
- Просмотр PDF, избранное, история чтения
- Админ-панель: добавление, редактирование и удаление книг

## Требования

| Компонент | Версия |

| XAMPP (Apache + MariaDB + PHP) | 8.x |

## Быстрый старт

### 1. Клонирование и зависимости

```bash
cd apaas
flutter pub get
```

### 2. База данных

1. Запустите **XAMPP** → включите **Apache** и **MySQL**.
2. Откройте [phpMyAdmin](http://localhost/phpmyadmin).
3. Создайте базу `electronic_library` (или импортируйте дамп).
4. Импортируйте SQL-файл из корня репозитория BasedTree:

   ```
   electronic_library (2).sql
   ```

### 3. PHP API (backend)

1. Скопируйте папку `library_api` в `C:\xampp\htdocs\library_api`.
2. В файле подключения к БД (`db.php` или аналог) укажите:

   - хост: `127.0.0.1`
   - база: `electronic_library`
   - пользователь: `root`
   - пароль: *(пустой для XAMPP по умолчанию)*

3. Проверьте API в браузере:

   ```
   http://127.0.0.1/library_api/get_books.php
   ```

   Должен вернуться JSON со списком книг.

> URL API задан в `lib/services/api_service.dart`:
> `http://127.0.0.1/library_api`

### 4. Запуск приложения

**Windows (рекомендуется для разработки):**

```bash
flutter run -d windows
```

**Web:**

```bash
flutter run -d chrome
```

**Android** (эмулятор или устройство):

```bash
flutter devices
flutter run -d <device_id>
```

> Для Android-эмулятора замените `127.0.0.1` в `api_service.dart` на `10.0.2.2`.

## Поиск книг

На главном экране доступны два независимых поля:

- **Поиск по названию** — частичное совпадение в названии книги
- **Поиск по жанру** — частичное совпадение в жанре (например: «Роман», «Фэнтези»)

Фильтры работают одновременно: отображаются только книги, подходящие под оба условия.  
Кнопка **«Сбросить»** очищает фильтры.

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| «Ошибка подключения» при входе | Проверьте, что Apache запущен и API доступен по URL |
| Пустой список книг | Убедитесь, что БД импортирована и `get_books.php` возвращает данные |
| Не работает на Android-эмуляторе | Замените `127.0.0.1` на `10.0.2.2` в `api_service.dart` |
| `flutter pub get` падает | Выполните `flutter clean && flutter pub get` |
